## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing (row internals, chips) |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, screen horizontal margin |
| xl | 32px | Layout gaps between major blocks |
| 2xl | 48px | Major section breaks (e.g. above hero balance) |
| 3xl | 64px | Page-level spacing (rare on mobile) |

Exceptions:
- Tab bar and icon-only buttons (back, disconnect, chain switch icon) use a 44px minimum touch target regardless of visual icon size, per mobile tap-target accessibility. Pad with `xs`/`sm` inside a 44px hit area, do not shrink the tap target below it.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | regular (400) | 1.5 |
| Body | 16px | regular (400) | 1.5 |
| Heading | 20px | semibold (600) | 1.2 |
| Display | 32px | semibold (600) | 1.2 |

Notes:
- Exactly 4 sizes, 2 weights (400/600), per contract limits.
- Display (32px/600) is reserved for the hero total balance figure on Home and for the Cuenta-mode saldo in later phases. Never use Display for anything else in this phase.
- Heading (20px/600) is for screen titles and section headers (e.g. "Tus redes", "Actividad reciente").
- Label (14px/400) is for meta text: chain names next to balances, timestamps, helper text under inputs.
- Numeric balances use tabular figures (`font-variant-numeric: tabular-nums`) so per-chain amounts align in the breakdown list.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (white) | App background, screen canvas |
| Secondary (30%) | `#F4F4F5` (zinc-100) | Cards, balance breakdown rows, tab bar surface, input backgrounds |
| Accent (10%) | `#2563EB` (blue-600) | Primary CTA buttons only, active tab indicator, links, positive/success state (e.g. bridge "en tránsito" pill) |
| Destructive | `#DC2626` (red-600) | Destructive actions and error states only |

Accent reserved for: primary CTA buttons ("Enviar ARGt", "Depositar en la bóveda", "Bridgear ARGt", "Confirmar transferencia"), the active tab indicator/underline, inline links (e.g. "Ver en Morpho"), and the "en tránsito" bridge status pill. Never applied to secondary buttons, static balance text, or decorative elements — this keeps the balance numbers themselves neutral (black/zinc-900) so the eye reads them as data, not as an interactive affordance.

Destructive reserved for: "Retirar todo" confirmation, "Cerrar sesión" confirmation, transaction error banners, invalid-address inline validation.

Text colors: primary text `#18181B` (zinc-900), secondary/meta text `#71717A` (zinc-500), both on white/zinc-100 surfaces — keeps contrast ratio well above WCAG AA at the declared sizes.

No dark mode in this phase (24h timeline, CONTEXT.md keeps the system minimal). Note as a scope cut, not a decision to revisit mid-phase.
