<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Input de usuario (monto) → `approve`/`deposit`/`redeem` | Montos ingresados a mano; sin validación server-side |
| Contrato del vault (Morpho/DAMM) | Fuera de control de esta app; se confía en su lógica ERC-4626 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-03-01 | Tampering | `app/(tabs)/rendimiento/page.tsx` deposit | mitigate | `approve` con el monto exacto (no `type(uint256).max`) para limitar la exposición del allowance si el vault tuviera un bug |
| T-03-02 | Repudiation | "Retirar todo" | mitigate | Confirmación explícita con copy destructivo antes de ejecutar `redeem` del balance completo, evita retiros accidentales irreversibles |
</threat_model>
